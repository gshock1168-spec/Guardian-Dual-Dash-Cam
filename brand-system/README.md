# Guardian Brand System

Recommended URL:
https://guardian1.netlify.app/brand-system/

Installation:
1. Unzip this package.
2. Copy the entire `brand-system` folder into the publish/root folder of the existing Guardian Netlify site.
3. Redeploy the site.
4. Confirm `/brand-system/` opens publicly.
5. Paste that URL into HeyGen's website/brand-system importer.

The package includes the official app icon, transparent-background store badges, a machine-readable JSON brand profile, and the complete visual and messaging system.
